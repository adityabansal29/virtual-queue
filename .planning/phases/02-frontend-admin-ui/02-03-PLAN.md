<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request→ValidateSession | q_session cookie from untrusted browser; ValidateSession rejects tampered/expired tokens |
| browser inline script→POST /queue/exit | eventId injected into HTML by Go — must be JSON-escaped to prevent XSS |
| scheduler→Redis capacity keys | capacity:{eventId} and active:{eventId} are internal Redis keys; no external trust boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Elevation | q_session validation bypass | high | mitigate | token.ValidateSession uses HMAC-SHA256 with SESSION_SECRET; tampered or cross-signed tokens rejected with error |
| T-02-10 | Tampering | eventId injection into inline JS | medium | mitigate | Use fmt.Sprintf("%q", eventID) for Go string quoting to JSON-escape eventId before embedding in script; prevents XSS from crafted eventId values |
| T-02-11 | Tampering | Capacity counter manipulation via PUT /queue/rate | low | accept | Local dev only (D-06); comment in handler already flags for prod auth |
| T-02-12 | Denial of Service | scheduler tight-loop on zero headroom | low | mitigate | tick() returns immediately when headroom <= 0 (no Redis ZPOPMIN called); no busy loop |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No new packages; Go stdlib + existing dependencies only |
</threat_model>
