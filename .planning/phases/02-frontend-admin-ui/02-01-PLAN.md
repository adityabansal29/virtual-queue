<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→queue API | Untrusted origin making cross-origin requests; CORS policy enforced here |
| URL params→JS | ticketId and target URL read from query string; not sanitized before use |
| sessionStorage→redirect | target URL from sessionStorage used in window.location.href |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | CORS allowlist in router.go | medium | mitigate | Explicit origin allowlist (not wildcard); compare exact string match per D-03 |
| T-02-02 | Tampering | q_admission cookie set by queue.js | low | accept | Cookie is a signed JWT; tampering caught by origin QueueGuard HMAC verify |
| T-02-03 | Elevation | target URL in sessionStorage used as redirect destination | medium | mitigate | window.location.href redirect only — no script execution. URL is user-supplied but stays within the browser's own session; risk is open redirect, accepted for local dev scope |
| T-02-04 | Information Disclosure | ticketId in URL params | low | accept | ticketId is non-sensitive (not a secret); it is the lookup key, not the admission token |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No new packages installed in this plan; nginx:alpine is a well-known official image |
</threat_model>
