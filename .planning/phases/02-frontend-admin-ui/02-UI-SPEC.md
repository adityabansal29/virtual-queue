## State Coverage

### Queue Waiting Page — State Machine

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | Page load before first poll returns | `<p id="pos">` shows "Checking your position…" |
| Polling | Rank >= SSE_THRESHOLD (200) | Position + wait time displayed; no SSE connection |
| SSE active | Rank < 200, upgrade triggered | Position + wait time displayed; EventSource open |
| Constrained | `constrained: true` in poll/SSE response | Constrained banner shown; wait estimate hidden |
| Admitted | `type: admitted` event received | Redirect fires; no displayed state (transient) |
| SSE error | EventSource `onerror` fires | `id="status"` shows "Reconnecting…" |
| Poll error | `fetch` throws or non-200 | `id="status"` shows "Connection lost. Retrying…" |

### Admin Dashboard — State Machine

| State | Trigger | Visual |
|-------|---------|--------|
| No events | `GET /queue/events` returns `[]` | Event selector shows "No events active" option; stat cards show `—` |
| Event selected | User picks from dropdown | Immediate stats fetch; polling starts |
| Stats loaded | Poll returns 200 | Stat card values update |
| Stats error | Poll returns non-200 or throws | Stat cards show previous value with "(stale)" suffix |
| Update success | `PUT /queue/rate` returns 200 | Button briefly shows "Saved" (1.5s), reverts to "Update Config" |
| Update failure | `PUT /queue/rate` returns non-200 | Error message below button: "Update failed. Try again." |

### Stub Checkout — State Machine

| State | Trigger | Visual |
|-------|---------|--------|
| Valid session | `q_session` present and valid | Seat selection page rendered |
| Session expired/missing | `q_session` absent or invalid | Error page rendered (see Copywriting) |
| Purchase complete | "Complete Purchase" clicked, `POST /queue/exit` succeeds | Success state inline |
| Exit call failed | `POST /queue/exit` non-200 | Button re-enables; small error note: "Could not free slot. Please close this tab." |

## UI Considerations

Applicable state considerations resolved: 7 covered, 1 backstop, 1 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Admin event selector when `GET /queue/events` returns `[]` | ✅ covered | "No events active" option rendered in `<select>`; stat cards show `—` |
| loading | Queue page before first poll response | ✅ covered | `id="pos"` renders "Checking your position…" on page load |
| error | Queue page SSE `onerror` | ✅ covered | `id="status"` shows "Reconnecting…"; polling does not restart (SSE handles its own reconnect) |
| error | Queue page poll `fetch` failure | ✅ covered | `id="status"` shows "Connection lost. Retrying…"; interval continues |
| error | Admin dashboard poll failure | ✅ covered | Stat values retain last value with "(stale)" suffix |
| error | Stub checkout missing/expired session | ✅ covered | Go handler renders separate error page with session-expired copy and return link |
| constrained | Queue page `constrained: true` response | ✅ covered | Constrained banner shown; wait estimate element hidden |
| overflow | Position display for rank > 99,999 | 🧪 backstop | Display must not overflow container; visual test required at rank=500000 |
| zero-one-many | Admin stat cards when values are 0 | ⚠ unresolved | Planner assumption: 0 is a valid value and should display as "0", not "—" or empty. Confirm in implementation. |

## Layout Contract

### Queue Waiting Page

- Single-column, vertically centered in viewport
- `<main>` max-width: 480px, auto horizontal margins
- Top padding: 64px (3xl)
- Position display (28px) above wait estimate (16px), 8px gap
- Status message below wait estimate, 16px gap
- Constrained banner: full width of main, background #fef3c7 (amber-50), 16px padding, 8px border-radius

### Admin Dashboard

- Two-region layout: top bar (event selector + connection indicator) + content area
- Top bar: full width, secondary background (#f3f4f6), 16px vertical padding, 24px horizontal padding
- Stat cards: CSS grid, 3 columns on >= 768px, 2 columns on < 768px, 16px gap
- Each stat card: white background, 1px #e5e7eb border, 8px border-radius, 24px padding
- Stat value: display size (28px/600), accent color (#2563eb) for Headroom only when headroom < 10% of capacity
- Edit controls: below stat grid, 24px top margin, inline form (label + input + label + input + button), 8px gaps
- Update button: accent fill, white text, 8px vertical padding, 16px horizontal padding, 4px border-radius

### Stub Checkout

- Single-column, max-width 560px, auto horizontal margins
- Top padding: 48px (2xl)
- Seat grid: 3 columns, 8px gap between seats
- Each seat button: 48px × 48px, 1px border, 4px border-radius; selected state: accent fill, white text
- Complete Purchase button: full width of form area, 16px vertical padding, accent fill
