    **web/queue/queue.js** — D-15 one-line fix:

    Change line 23:
    ```js
    // BEFORE:
    document.cookie = 'q_admission=' + token + '; path=/; max-age=1800; SameSite=Strict';
    // AFTER:
    document.cookie = 'q_admission=' + token + '; path=/; max-age=1800; SameSite=Lax';
    ```
    This is the only change to queue.js. CloudFront serves `d1xxx.cloudfront.net` (queue page) and `d2yyy.cloudfront.net` (stub origin) — treated as different sites on the Public Suffix List. SameSite=Strict blocks the cookie on the admission redirect; Lax sends it on top-level GET navigations. Safe because the token is single-use (SETNX) and short-lived.

    After `eventID` is validated and before the existing `dest := fmt.Sprintf(...)` redirect, add:
    ```go
    // D-19: check for per-event custom HTML in S3; redirect to CloudFront events URL if found.
    if h.s3Client != nil && h.cfg.EventsBucketName != "" && h.cfg.EventsCFDomain != "" {
        key := fmt.Sprintf("events/%s/page.html", eventID)
        _, err := h.s3Client.HeadObject(c.Request.Context(), &s3.HeadObjectInput{
            Bucket: aws.String(h.cfg.EventsBucketName),
            Key:    aws.String(key),
        })
        if err == nil {
            // Custom page exists — redirect to CloudFront events distribution

    ```

    **handler_admin.go — presigned PUT URL endpoint** (D-18):

    Add a new handler method `GetPageUploadURL`:
    ```go
    // GetPageUploadURL handles GET /queue/events/:id/page-upload-url
    // Returns a short-lived presigned S3 PUT URL for uploading a per-event HTML page.
    func (h *Handler) GetPageUploadURL(c *gin.Context) {
        if h.s3Presign == nil || h.cfg.EventsBucketName == "" {
            c.JSON(http.StatusNotImplemented, gin.H{"error": "S3 not configured"})
            return
        }
        eventID := c.Param("id")
        if eventID == "" {
            c.JSON(http.StatusBadRequest, gin.H{"error": "eventId required"})
            return
        }
        key := fmt.Sprintf("events/%s/page.html", eventID)
        req, err := h.s3Presign.PresignPutObject(c.Request.Context(), &s3.PutObjectInput{
            Bucket:      aws.String(h.cfg.EventsBucketName),
            Key:         aws.String(key),
            ContentType: aws.String("text/html"),
        }, s3.WithPresignExpires(15*time.Minute))
        if err != nil {
            c.JSON(http.StatusInternalServerError, gin.H{"error": "presign failed"})
            return
        }
        c.JSON(http.StatusOK, gin.H{"url": req.URL})
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → S3/CloudFront (queue page) | Publicly readable via CloudFront; S3 bucket itself has no public access |
| admin dashboard → queue API → S3 | Presigned PUT URL scoped to events/{eventId}/page.html path only |
| CloudFront → S3 | OAC sigv4 signing — only CloudFront distribution can read from the bucket |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-13 | Tampering | Per-event HTML upload (D-18) | high | mitigate | Presigned PUT URL scoped to exact key `events/{eventId}/page.html`; ContentType restricted to `text/html`; 15-minute expiry; admin dashboard has no auth (D-06 Phase 2 deferred), so rely on network-level protection (VPC, not public in prod) |
| T-03-14 | Information Disclosure | S3 events bucket contents | medium | mitigate | Public access blocked on S3; CloudFront OAC is the only read path; no ListBucket permission granted |
| T-03-15 | Spoofing | SameSite=Lax on q_admission | low | accept | D-15: Lax is the correct setting for cross-site top-level navigation; token is single-use (SETNX) so a CSRF attack that delivers the token to the wrong origin just burns it without granting access |
| T-03-16 | Elevation of Privilege | CORS_ALLOWED_ORIGINS env var | medium | mitigate | Allowlist approach (not wildcard); only the CloudFront distribution URL added; set explicitly in ECS task definition from Terraform output |
| T-03-SC | Tampering | No npm/pip/cargo installs | low | accept | AWS SDK v2 S3 package is a Go module addition to go.sum — hash-verified |
