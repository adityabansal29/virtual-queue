    **DynamoDB module** (`infra/modules/dynamodb/main.tf`):

    Three tables per INFRA-05:

    *queue-sessions* (audit per ticket, D-20):
    ```hcl
    resource "aws_dynamodb_table" "queue_sessions" {
      name         = "${var.environment}-queue-sessions"
      billing_mode = "PAY_PER_REQUEST"
      hash_key     = "ticketId"

      attribute {
        name = "ticketId"
        type = "S"
      }

      ttl {
        attribute_name = "expiresAt"
        enabled        = true
      }

      tags = { Environment = var.environment }
    }
    ```

    *queue-events* (event config table, INFRA-05):
    ```hcl
    resource "aws_dynamodb_table" "queue_events" {
      name         = "${var.environment}-queue-events"
      billing_mode = "PAY_PER_REQUEST"
      hash_key     = "eventId"

      attribute {
        name = "eventId"
        type = "S"
      }

      tags = { Environment = var.environment }
    }
    ```

    *queue-audit-log* (immutable event log, INFRA-05):
    ```hcl
    resource "aws_dynamodb_table" "queue_audit_log" {
      name         = "${var.environment}-queue-audit-log"
      billing_mode = "PAY_PER_REQUEST"
      hash_key     = "eventId"
      range_key    = "timestamp"

      attribute {
        name = "eventId"
        type = "S"
      }

      attribute {
        name = "timestamp"
        type = "S"
      }

      ttl {
        attribute_name = "expiresAt"
        enabled        = true
      }

      tags = { Environment = var.environment }
    }
    ```

    Outputs: `queue_sessions_table_arn`, `queue_sessions_table_name`, `queue_events_table_arn`, `queue_events_table_name`, `queue_audit_log_table_arn`.

    **SQS module** (`infra/modules/sqs/main.tf`) per D-21 / INFRA-06:
    ```hcl
    resource "aws_sqs_queue" "admission_events" {
      name                        = "${var.environment}-admission-events.fifo"
      fifo_queue                  = true
      content_based_deduplication = true
      visibility_timeout_seconds  = 30
      message_retention_seconds   = 86400  # 1 day

      tags = { Environment = var.environment }
    }
    ```

    Note: FIFO queue names MUST end in `.fifo` — ensure the name attribute includes it.

    Outputs: `admission_events_queue_url`, `admission_events_queue_arn`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ECS task → SSM | Task execution role must have ssm:GetParameters; secret never touches Terraform state |
| ECS task → DynamoDB/SQS | Task role scoped to specific table/queue ARNs — no wildcard resource |
| ElastiCache → ECS tasks | Redis sits in private subnets; sg_redis only allows inbound from sg_ecs_tasks |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Information Disclosure | SSM SecureString → ECS env var | high | mitigate | D-07: secrets injected via ECS secrets block (SSM path), never written to Terraform state or tfvars; task execution role policy scoped to specific parameter ARNs |
| T-03-05 | Tampering | DynamoDB queue-sessions | medium | mitigate | IAM task role grants only `dynamodb:PutItem` (not Delete/Scan); TTL on sessions table limits exposure window |
| T-03-06 | Spoofing | SQS FIFO admission-events | medium | mitigate | `sqs:SendMessage` scoped to specific queue ARN; FIFO + content-based dedup prevents replay injection |
| T-03-07 | Denial of Service | ElastiCache Redis (no auth in dev) | medium | accept | Dev environment only; sg_redis restricts to ECS tasks SG; production would add AUTH token |
| T-03-08 | Elevation of Privilege | ECS task IAM role over-permission | high | mitigate | Task role policy uses specific ARNs for DynamoDB tables and SQS queue; no wildcard `*` resources in production paths |
| T-03-SC | Tampering | No npm/pip/cargo installs in this plan | low | accept | No package manager installs in this Terraform plan |
</threat_model>
