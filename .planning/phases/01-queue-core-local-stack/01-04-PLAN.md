    ## internal/api/handler_admin.go
    Package `api`. Two methods on *Handler:

    ### `func (h *Handler) UpdateRate(c *gin.Context)`
    Implements PUT /queue/rate/:eventId:
    1. Extract eventID from `c.Param("eventId")`.
    2. Parse body JSON: `struct{ Rate int64 json:"rate"; Capacity int64 json:"capacity,omitempty" }`.
    3. If Rate > 0: `h.rdb.Set(ctx, "rate:"+eventID, rate, 0)` — no TTL (persists until changed).
    4. If Capacity > 0: `h.rdb.Set(ctx, "capacity:"+eventID, capacity, 0)` — scaffolded for D-06 future enforcement; not read by scheduler in Phase 1.
    5. Respond: `c.JSON(200, gin.H{"eventId": eventID, "rate": rate, "capacity": capacity, "message": "rate updated; takes effect on next scheduler tick"})`.
    Error: if body parse fails → 400 `{"error": "invalid request body"}`.

    ### `func (h *Handler) GetConfig(c *gin.Context)`
    Implements GET /queue/config/:eventId:
    1. Extract eventID from `c.Param("eventId")`.
    2. Fetch in parallel using Redis pipeline or sequential Gets (ponytail: pipeline if latency becomes important):
       - `depth, _ = h.rdb.ZCard(ctx, "queue:"+eventID).Result()`
       - `activeStr, _ = h.rdb.Get(ctx, "active:"+eventID).Result()` — parse to int64, default 0
       - `rateStr, _ = h.rdb.Get(ctx, "rate:"+eventID).Result()` — parse to int64, default h.cfg.DefaultAdmitRate
       - `capacityStr, _ = h.rdb.Get(ctx, "capacity:"+eventID).Result()` — parse to int64, default 0 (D-06: not enforced in Phase 1)
    3. Compute estimated drain time: if rate > 0, `estimatedSec = depth / rate * 60` (integer division — sufficient for Phase 1); else -1 (unknown).
    4. Respond: `c.JSON(200, gin.H{"eventId": eventID, "queueDepth": depth, "activeUsers": active, "admitRate": rate, "capacity": capacity, "estimatedDrainSec": estimatedSec})`.

    ## scripts/verify.sh
    Executable bash script (`chmod +x`). Shebang: `#!/usr/bin/env bash`. Set `set -euo pipefail` at top. Define helper `pass()` prints "[PASS] $1" in green, `fail()` prints "[FAIL] $1" in red and sets EXIT_CODE=1. Initialize `EXIT_CODE=0`.

    The script assumes `docker compose up` is already running. It does NOT start docker compose (caller's responsibility — run via `make verify` after `make up`).

    ### Criterion 1: docker compose up starts stack; POST /queue/join returns ticketId
    ```
    # Check queueserver is reachable
    HEALTH=$(curl -sf http://localhost:8080/health 2>/dev/null || echo "")
    if echo "$HEALTH" | grep -q '"ok":true'; then pass "Criterion 1a: queueserver health OK"; else fail "Criterion 1a: queueserver not reachable"; fi

    # Join and capture ticketId
    JOIN=$(curl -sf -X POST http://localhost:8080/queue/join \
      -H "Content-Type: application/json" -d '{"eventId":"evt-001"}' 2>/dev/null || echo "")
    TICKET=$(echo "$JOIN" | grep -o '"ticketId":"[^"]*"' | cut -d'"' -f4)
    if [ -n "$TICKET" ]; then pass "Criterion 1b: POST /queue/join returned ticketId=$TICKET"; else fail "Criterion 1b: no ticketId in response"; fi
    ```

    ### Criterion 2: poll returns position and upgrade_to_sse hint
    ```
    # Join a second ticket for poll test (TICKET from above might be admitted already)
    JOIN2=$(curl -sf -X POST http://localhost:8080/queue/join \
      -H "Content-Type: application/json" -d '{"eventId":"evt-001"}' 2>/dev/null || echo "")
    TICKET2=$(echo "$JOIN2" | grep -o '"ticketId":"[^"]*"' | cut -d'"' -f4)

    POLL=$(curl -sf "http://localhost:8080/queue/status/${TICKET2}?mode=poll" 2>/dev/null || echo "")
    if echo "$POLL" | grep -q '"type":"position"'; then pass "Criterion 2a: poll returns position type"; else
      # May be admitted immediately if queue is empty — check for admitted instead
      if echo "$POLL" | grep -q '"type":"admitted"'; then pass "Criterion 2a: poll returned admitted (queue was empty)";
      else fail "Criterion 2a: poll did not return position or admitted"; fi
    fi
    if echo "$POLL" | grep -q '"upgrade_to_sse":true'; then pass "Criterion 2b: upgrade_to_sse:true when rank < 200"; else
      # Only required when rank < 200; if admitted, skip this check
      if echo "$POLL" | grep -q '"type":"admitted"'; then pass "Criterion 2b: skipped (already admitted)";
      else fail "Criterion 2b: upgrade_to_sse not true for rank < 200"; fi
    fi
    ```

    ### Criterion 3: SSE stream delivers position and admitted events
    ```
    JOIN3=$(curl -sf -X POST http://localhost:8080/queue/join \
      -H "Content-Type: application/json" -d '{"eventId":"evt-001"}' 2>/dev/null || echo "")
    TICKET3=$(echo "$JOIN3" | grep -o '"ticketId":"[^"]*"' | cut -d'"' -f4)

    # Open SSE stream for 4 seconds (scheduler admits within 1s)
    SSE_OUTPUT=$(curl -sf -N --max-time 4 "http://localhost:8080/queue/status/${TICKET3}?mode=sse" 2>/dev/null || echo "")
    if echo "$SSE_OUTPUT" | grep -q '"type":"position"'; then pass "Criterion 3a: SSE delivered position event"; else fail "Criterion 3a: SSE did not deliver position event"; fi
    if echo "$SSE_OUTPUT" | grep -q '"type":"admitted"'; then pass "Criterion 3b: SSE delivered admitted event"; else fail "Criterion 3b: SSE did not deliver admitted event (timeout?)"; fi
    ```

    ### Criterion 4: QueueGuard one-time enforcement
    ```
    # Get a fresh ticket and wait for admission JWT
    JOIN4=$(curl -sf -X POST http://localhost:8080/queue/join \
      -H "Content-Type: application/json" -d '{"eventId":"evt-001"}' 2>/dev/null || echo "")
    TICKET4=$(echo "$JOIN4" | grep -o '"ticketId":"[^"]*"' | cut -d'"' -f4)

    # Poll until admitted (max 5s)
    JWT=""
    for i in $(seq 1 5); do
      POLL4=$(curl -sf "http://localhost:8080/queue/status/${TICKET4}?mode=poll" 2>/dev/null || echo "")
      JWT=$(echo "$POLL4" | grep -o '"token":"[^"]*"' | cut -d'"' -f4)
      [ -n "$JWT" ] && break
      sleep 1
    done

    if [ -z "$JWT" ]; then
      fail "Criterion 4: could not obtain admission JWT within 5s"
    else
      # First admission
      HTTP1=$(curl -sf -o /dev/null -w "%{http_code}" -b "q_admission=$JWT" http://localhost:8081/ 2>/dev/null || echo "000")
      if [ "$HTTP1" = "200" ]; then pass "Criterion 4a: first admission HTTP 200"; else fail "Criterion 4a: first admission returned HTTP $HTTP1 (expected 200)"; fi

      # Second admission (replay) — must be 403
      HTTP2=$(curl -sf -o /dev/null -w "%{http_code}" -b "q_admission=$JWT" http://localhost:8081/ 2>/dev/null || echo "000")
      if [ "$HTTP2" = "403" ]; then pass "Criterion 4b: token replay returned HTTP 403"; else fail "Criterion 4b: token replay returned HTTP $HTTP2 (expected 403)"; fi

      # Redis introspection: token:{jti} must exist on redis-origin
      JTI=$(echo "$JWT" | cut -d. -f2 | base64 -d 2>/dev/null | tr -d '\n' | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('jti',''))" 2>/dev/null || echo "")
      if [ -n "$JTI" ]; then
        EXISTS=$(docker compose exec -T redis-origin redis-cli EXISTS "token:$JTI" 2>/dev/null || echo "0")
        if echo "$EXISTS" | grep -q "1"; then pass "Criterion 4c: token:{jti} exists in redis-origin (SETNX confirmed)"; else fail "Criterion 4c: token:{jti} not found in redis-origin"; fi
      fi
    fi
    ```

    ### Criterion 5: env vars — two distinct secrets, wrong-secret rejection
    ```
    # Check .env.example has both secrets and they differ
    if [ -f ".env.example" ]; then
      ADM=$(grep "^ADMISSION_SECRET=" .env.example | cut -d= -f2)
      SES=$(grep "^SESSION_SECRET=" .env.example | cut -d= -f2)
      if [ -n "$ADM" ] && [ -n "$SES" ] && [ "$ADM" != "$SES" ]; then
        pass "Criterion 5a: ADMISSION_SECRET and SESSION_SECRET are distinct non-empty values in .env.example"
      else
        fail "Criterion 5a: secrets missing or identical in .env.example"
      fi
    else
      fail "Criterion 5a: .env.example not found"
    fi

    # Wrong-secret rejection: present a JWT signed with a made-up secret
    FAKE_JWT="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJ0ZXN0IiwiZXhwIjo5OTk5OTk5OTk5fQ.FAKESIGNATURE"
    HTTP_FAKE=$(curl -sf -o /dev/null -w "%{http_code}" -b "q_admission=$FAKE_JWT" http://localhost:8081/ 2>/dev/null || echo "000")
    if [ "$HTTP_FAKE" != "200" ]; then
      pass "Criterion 5b: wrong-secret JWT rejected (HTTP $HTTP_FAKE, not 200)"
    else
      fail "Criterion 5b: wrong-secret JWT was accepted (should be rejected)"
    fi
    ```

    ```
    if [ "$EXIT_CODE" = "0" ]; then

      echo "Some criteria FAILED — see output above"
    fi
    exit "$EXIT_CODE"
    ```
